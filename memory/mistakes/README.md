# mistake-log 작성 가이드

AI가 저지른 실수를 기록하고 규칙으로 변환하는 파일.
파일명: `YYYY-MM-DD-{도메인}-{한줄요약}.md`

---

## 작성 템플릿

```markdown
# {한줄 요약}

날짜: YYYY-MM-DD
도메인: {트레이딩 / 백엔드 / 기획 / 기타}
이슈: #{번호} (있는 경우)

## 어떤 실수였나
> 구체적인 상황과 AI가 한 출력 내용

## 왜 발생했나
- [ ] 컨텍스트 부족 (어떤 정보가 없었는가?)
- [ ] 규칙 누락 (ai-rules.md에 없던 규칙)
- [ ] 모델 한계 (도메인 지식 부족 등)
- [ ] 이슈 불명확 (수락 기준 미흡)
- [ ] 기타:

## 어떻게 발견했나
> 직접 발견 / 테스트 실패 / 운영 중 발견 등

## 어떻게 해결했나
> 실제 수정 방법

## 규칙으로 변환
> ai-rules.md 또는 hooks에 추가할 내용

추가 위치: `harness/ai-rules.md` > {섹션명}
추가 내용:
\`\`\`
{추가할 규칙 텍스트}
\`\`\`

## 재발 방지 확인
- [ ] ai-rules.md에 반영됨
- [ ] 같은 작업 재실행 시 실수 재현 안 됨 확인
```

---

## 예시

```markdown
# 트레이딩 신호 필터에서 엣지 케이스 누락

날짜: 2026-06-05
도메인: 트레이딩

## 어떤 실수였나
거래량 0인 경우에 대한 처리 없이 필터 로직 구현.
ZeroDivisionError 발생.

## 왜 발생했나
- [x] 이슈 불명확 (수락 기준에 엣지 케이스 명시 없음)

## 규칙으로 변환
추가 위치: `harness/ai-rules.md` > 작업 전 규칙
추가 내용:
수치 계산 로직 구현 시 0, None, 빈 배열 케이스를 수락 기준에 포함하도록 질문한다.
```

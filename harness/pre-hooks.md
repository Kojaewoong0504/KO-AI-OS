# pre-hooks.md

작업 시작 전 자동으로 실행하는 검사 목록.
이슈를 받았을 때, 또는 새 작업을 시작하기 전에 반드시 통과해야 한다.

---

## 이슈 린트 (이슈 기반 작업 시)

아래 항목이 모두 채워져 있는지 확인한다.
하나라도 비어 있으면 작업을 시작하지 않고 질문을 먼저 생성한다.

- [ ] **목적** — 이 작업을 왜 하는가?
- [ ] **수락 기준** — 완료 조건이 명확한가?
- [ ] **범위** — 무엇을 포함하고 무엇을 포함하지 않는가?
- [ ] **제약** — 건드리면 안 되는 영역이 있는가?

불명확 시 생성할 질문 형식:
```
이슈 #N을 시작하기 전에 확인이 필요합니다.

[추정] {불명확한 항목}: {현재 추정값}
→ 이 추정이 맞나요, 아니면 다른 의도가 있나요?
```

## 컨텍스트 주입 체크

작업 시작 전 아래 파일들이 컨텍스트에 포함되어 있는지 확인한다.

- [ ] `harness/ai-rules.md` 로드됨
- [ ] 관련 `skills/` 파일 로드됨 (있는 경우)
- [ ] 관련 `memory/mistakes/` 파일 확인됨 (같은 도메인)
- [ ] 관련 `memory/decisions/` 파일 확인됨 (아키텍처 관련 작업)

---

## 범위 확인

- [ ] 이 작업이 단일 관심사인가? (복수면 이슈 분리 제안)
- [ ] 예상 변경 파일이 5개 이하인가? (초과 시 단계 분리 검토)
- [ ] 기존 동작에 영향을 주는 변경이 포함되어 있는가? (있으면 `[주의]` 표시)

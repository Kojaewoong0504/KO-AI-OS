# gc-checklist.md

주기적으로 실행하는 가비지 컬렉션 체크리스트.
GC 자체도 이슈로 등록해 AI에게 맡긴다.

---

## 매주 — 코드 GC

이슈 제목: `[GC] 코드 정리 YYYY-WXX`

```
목적: 코드베이스의 불필요한 요소 제거
수락 기준:
  - 미사용 함수·변수·import 목록 제시
  - 중복 로직 목록 제시
  - 제거 가능 여부 판단 (자동 제거 X, 목록만)
범위: src/ 전체
제약: 실제 삭제는 사람이 직접 확인 후 진행
```

체크 항목:
- [ ] 2주 이상 호출되지 않은 함수
- [ ] 사용되지 않는 import
- [ ] 중복된 유틸리티 함수
- [ ] 주석 처리된 코드 블록
- [ ] TODO 주석 중 오래된 것 (30일 이상)

---

## 격주 — 하네스 GC

이슈 제목: `[GC] 하네스 정리 YYYY-MM`

체크 항목:
- [ ] `ai-rules.md`에서 적용되지 않는 규칙 확인

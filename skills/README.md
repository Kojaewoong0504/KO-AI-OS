# Skills

도메인별 재사용 가능한 작업 패턴 모음.
새 스킬은 아래 구조를 따른다.

---

## 스킬 구조

```
skills/
└── {skill-name}/
    ├── SKILL.md        # 스킬 설명, 사용법, 체크리스트
    ├── examples/       # 실제 적용 예시
    └── templates/      # 재사용 템플릿
```

## SKILL.md 작성 형식

```markdown
# {스킬 이름}

## 언제 쓰는가
## 사용 방법
## 체크리스트
## 예시
## 알려진 한계
## 업데이트 기록
```

## 스킬 추가 기준

- 같은 작업을 2번 이상 반복했을 때
- 반복할 때마다 같은 실수가 생길 때
- 특정 도메인에서 AI에게 매번 같은 컨텍스트를 줄 때
